Elementos HTML do <h1> até <h6>

O elemento <h1> é muito importante, deixa o tamanho da fonte bem grande, normalmente é usado no título da página.

O elemento <h2> é importante, deixa o tamanho da fonte grande, normalmente é usado para separar as seções principais.

O elemento <h3> Tem uma importancia media, deixa o tamanho da fonte media, normalmente é usado para separar as sub-seções

O elemento <h4> Deixa a fonte do tamanho normal e, é usado normalmente para títulos de listas ou boxes

O elemento <h5> Não é muito importante, deixa a fonte pequena, normalmente usada em notas de rodapé de seções

O elemento <h6> Não tem nada de importante, deixa a fonte muito pequena, normalmente nunca é usado
